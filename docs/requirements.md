# Жүйеге қойылатын талаптар

## Функционалдық талаптар

### FR-01
Жүйе тіркелмеген пайдаланушыға каталогты қарауға мүмкіндік
беруі тиіс, ал брондау тек авторизациядан кейін қолжетімді болуы тиіс.

### FR-02
Жүйе турларды ел, қала, күн аралығы, түн саны, баға және
тамақтану түрі бойынша сүзгілеуі тиіс.

### FR-03
Жүйе серіктес API арқылы бос орын туралы ақпарат алуы тиіс.

### FR-04
Жүйе брондау кезінде жолаушының аты-жөнін және төлқұжат
деректерін енгізуді қамтамасыз етуі тиіс.

### FR-05
Жүйе бронды 30 минутқа «күтуде» статусында сақтауы тиіс.

### FR-06
Төлем расталғаннан кейін жүйе PDF форматында ваучер қалыптастыруы тиіс.

### FR-07
Менеджер күрделі өтінімдерді қабылдап, өңдей алуы тиіс.

### FR-08
Директор мен бухгалтер сатылым бойынша есепті Excel форматына
жүктей алуы тиіс.

## Функционалдық емес талаптар

- Каталогтың жауап беру уақыты 3 секундтан аспауы тиіс.
- Жүйенің айлық қолжетімділігі кемінде 99,5% болуы тиіс.
- Құпиясөздер хэштеліп сақталуы тиіс.
- Төлқұжат деректері шифрлануы тиіс.
- Жүйе қазақ және орыс тілдерін қолдауы тиіс.
- Сақтық көшірме тәулігіне бір рет жасалуы тиіс.

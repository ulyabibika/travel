# Alatau Travel

## Жоба туралы

«Alatau Travel» туристік агенттігінің ақпараттық жүйесі.

Жүйе клиентке турларды іздеуге, салыстыруға, брондауға және
онлайн төлем жасауға мүмкіндік береді. Сонымен қатар менеджер,
бухгалтер және директор үшін өтінімдер мен есептерді басқаруды
автоматтандыру қарастырылған.

## Жобаның мақсаты

Турды іздеуден бастап төлем мен электронды ваучерді алуға дейінгі
процесті бір ақпараттық жүйеге біріктіру.

## Негізгі функциялар

- Турларды іздеу және сүзгілеу
- Турды брондау
- Онлайн төлем
- Электронды ваучер қалыптастыру
- Клиенттік базаны басқару
- Есеп беру
- Хабарлама жіберу
